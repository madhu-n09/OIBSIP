# 📊 Retail Sales Data - Exploratory Data Analysis(EDA)

## 📌 Project Overview
This project performs Exploratory Data Analysis(EDA) on a retail sales dataset to identify sales trends, product performance, customer distribution, and business insights.

## 📂Dataset
- The dataset contains retail sales transaction records with the following columns:
- Order ID
- Order Date
- Customer ID
- Customer Date
- Age
- Gender
- Product Category
- Product Name
- Sales
- Quantity
- Price Per Unit
- City
- State
- Payment Mode

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib
- Seaborn
- VS Code
- Jupyter Notebook

## 🔎Analysis Performed
- Data Loading
- Data Cleaning
- Descriptive Statistics
- Monthly Sales Analysis
- Quarterly Sales Analysis
- Top Selling Products
- Revenue by Product Category
- Correlation Heatmap
- Sales Distribution
- Gender Distribution
- Business Insights
- Conclusion
- Recommendations

## 💡 Key Insights
- Electronics generated the highest revenue.
- Most sales transactions were of low value.
- Male customers were slightly more than female customers.
- The frequency of transactions decreased as the sales amount increased.
- Quantity and Sales showed a positive correlation.

## ✅ Conclusion
This analysis provides valuable insights that help businesses make better decisions regarding inventory management, product categories, and sales planning.
